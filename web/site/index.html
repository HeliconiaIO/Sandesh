Explore protocol support

Built for local development

Your test mail stays in your environment.

Sandesh is a development tool, not a hosted inbox. Its defaults keep the test loop close to your app and under your control.

NETWORK

Loopback by default

Listeners bind to your own machine unless you deliberately configure another address.

STORAGE

Local data files

SQLite state and message blobs live in the data directory you choose.

CONTENT

Inspectable, not executed

Email HTML is sandboxed. Extracted links are displayed but never fetched by Sandesh.

A working mail environment

Built for the whole test loop.
