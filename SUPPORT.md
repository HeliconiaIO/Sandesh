# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/HeliconiaIO/Sandesh/discussions).
- **Bugs:** [open an issue](https://github.com/HeliconiaIO/Sandesh/issues/new/choose) using the bug
  report form.
- **Security vulnerabilities:** never in public. Follow [SECURITY.md](SECURITY.md).
- **Anything else**, including commercial enquiries: <hello@heliconia.io>.

Before asking, the [user guides](docs/guides/README.md) and the
[user manual](docs/MASTER_USER_MANUAL.md) cover installation, configuration and every feature.

Sandesh is maintained by a small team. Issues are triaged on a best-effort basis, with no
guaranteed response time except for security reports.
